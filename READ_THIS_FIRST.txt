HEART & SOUL — PRIVATE ORDER STORE

This build stops using the Netlify Forms API for the owner dashboard.

Upload ALL ZIP contents to the ROOT of GitHub, commit, and wait for Netlify to publish.

Then open:
https://heartandsoulmums.netlify.app/orders/

You must see:
BUILD: PRIVATE-ORDERS-STORE

Only OWNER_DASHBOARD_KEY is required now.
NETLIFY_ACCESS_TOKEN and MUM_ORDER_FORM_ID are no longer used by the Orders Dashboard.

IMPORTANT:
Old orders already sitting in Netlify Forms will not automatically appear in this new dashboard.

After this build is live, submit ONE NEW mock order from the NORMAL customer website.
That new order will:
1. still save to Netlify Forms as a backup
2. also save to the private Orders Dashboard store

Then open /orders/ and log in. That new order should appear.

Order statuses are persistent in this version.
