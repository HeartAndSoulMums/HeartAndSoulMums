HEART & SOUL — DISPLAY FIX

We found the real remaining bug.

The owner login request was succeeding with HTTP 200 and returning the full Jordan Davis order.
The dashboard was also rendering.

But CSS had:
  .login-shell { display:grid; }

That author CSS rule overrode the browser's normal hidden behavior, so:
  loginView.hidden = true

did NOT actually hide the login screen.

This build adds:
  [hidden] { display:none !important; }

It also fixes the order-status update action.

   BUILD: DISPLAY-FIX
